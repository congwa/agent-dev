## 目录组织约定

- 每个主题系列一个文件夹，命名格式：`YYYY-MM_中文标题`（如 `2026-07_agent当前发展`），月份为该系列的写作月份

- 所有调研均标注调研日期，数据（star 数、commit 时间等）以调研当日实测为准
- 未经官方一手资料确认的第三方信息会在文中单独标注
